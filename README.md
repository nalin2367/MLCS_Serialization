# Text Classification using Multinomial Naive Bayes

This project classifies documents from the `scikit-learn` 20 Newsgroups dataset using a TF-IDF vectorizer and a Multinomial Naive Bayes classifier.

## Files
* `train.py`: Downloads data, trains the model, evaluates accuracy, and exports the model.
* `requirements.txt`: Python package dependencies.
* `20newsgroups_model.joblib`: The trained model artifact.
